# network-automation-lab
Network Automation using Python and Netmiko
Welcome to the Network Automation Lab repository. This project contains real-world network automation scripts using Python and Netmiko for Cisco devices. This repository is designed for students and network engineers to learn and practice network automation in enterprise environments.

Project Objective

The main goal of this repository is to help students and engineers:

Learn Network Automation using Python

Automate Cisco router and switch configurations

Understand real-world automation workflows

Learn Git and GitHub version control

Practice enterprise-level automation tasks

Technologies Used

Python 3

Netmiko

Cisco IOS

SSH Protocol

Git and GitHub

Scripts Included
1. VLAN Configuration Script

File: vlan_config.py

This script connects to multiple Cisco switches and:

Creates VLAN

Assigns VLAN name

Saves configuration

Verifies VLAN

Example use case:
Enterprise network VLAN provisioning

2. BGP Neighbor Check Script

File: bgp_check.py

This script connects to routers and:

Checks BGP neighbor status

Identifies DOWN neighbors

Helps in network monitoring

Example use case:
NOC network monitoring automation

3. Interface Status Check Script

File: interface_check.py

This script:

Checks interface status

Identifies down interfaces

Helps in troubleshooting

Example use case:
Network health monitoring
